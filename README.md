# Rofi Kaomoji

> [!WARNING]
> This is a personal project created with my own setup in mind, so it only supports Wayland for now.

A simple Kaomoji picker using [Rofi](https://github.com/davatorium/rofi).

## Features

- Select a Kaomoji and copy using [wl-clipboard](https://github.com/bugaevc/wl-clipboard).
- Fuzzy find Kaomoji with keywords.
- Customizable list of Kaomojis using the `.config/kaomoji.json` config file.
